# SeixOS Desktop

O app de marca e marketing da Seix Studios, com o Claude trabalhando em segundo plano.

## Instalar

Abra o Claude Code e cole:

```
Instale o SeixOS para mim seguindo https://raw.githubusercontent.com/danielvieira-dev/seixos-releases/main/INSTALL.md
```

Ele baixa a versão mais recente daqui, instala e abre o app. As próximas versões chegam sozinhas.

Este repositório guarda só os instaladores e as instruções de instalação. O código do app não fica aqui.
